Windows에서 설치하기

SingQ X는 무료로 나눠 드리는 앱이라 유료 코드 서명 인증서를 쓰지 않습니다. 그래서 받거나 설치할 때 Windows와 브라우저가 경고를 띄웁니다. 앱에 문제가 있다는 뜻이 아니라, 게시자를 확인해 줄 서명이 없다는 뜻입니다.

  1. 브라우저가 "흔히 받는 파일이 아님"이라고 하면: 받은 파일 옆 '…' ▸ '유지'(Chrome은 '계속')를 누릅니다.
  2. 받은 SingQ-X-windows.zip을 오른쪽 클릭 ▸ '모두 압축 풀기'로 풀고, 안의 SingQ-X-windows-setup.exe를 두 번 누릅니다.
  3. "Windows의 PC 보호" 창이 뜨면: '추가 정보' ▸ '실행'을 누릅니다.
  4. 관리자 권한 없이 내 사용자 폴더에 설치되고, 시작 메뉴에 'SingQ X'가 생깁니다.

받은 파일이 이 페이지의 파일과 같은지 확인하려면 PowerShell에서 아래처럼 지문(SHA-256)을 보고, 릴리스 페이지에 적힌 값과 견줘 보세요. 같으면 안심하고 설치하셔도 됩니다.

Get-FileHash "$env:USERPROFILE\Downloads\SingQ-X-windows\SingQ-X-windows-setup.exe"

그래도 마음에 걸리시면 설치하지 않으셔도 괜찮습니다.

AI 자동 마킹과 보컬 나누기는 처음 쓸 때 AI 모델(합쳐서 약 1.4GB)을 한 번 내려받습니다. 모든 계산은 PC 안에서 합니다.

Installing on Windows (English)

SingQ X is free and is not signed with a paid code-signing certificate, so Windows and your browser show warnings when you download or install it. The warnings mean the publisher can't be verified, not that the app is harmful.

  1. If your browser says the file "isn't commonly downloaded": click '…' next to the download ▸ 'Keep' (in Chrome, 'Keep anyway').
  2. Right-click the downloaded SingQ-X-windows.zip ▸ 'Extract All', then double-click SingQ-X-windows-setup.exe inside.
  3. If "Windows protected your PC" appears: click 'More info' ▸ 'Run anyway'.
  4. SingQ X installs in your user folder without administrator rights and appears in the Start menu.

To check that your file is the same as ours, run the command above in PowerShell and compare the SHA-256 with the value on the release page. If you'd rather not install it, that's fine too.
